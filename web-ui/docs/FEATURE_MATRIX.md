# 功能矩阵

2026-11-03，Windows 本机，Node 24.22.2、npm 11.19.1，现有 Nova Phase 2 FastAPI 与 Ollama。

| 能力 | 状态 | 验证证据 |
| --- | --- | --- |
| 本机页面与设置 | 通过 | 浏览器显示「真实后端」「后端在线」。已核实路由在诊断表显示。 |
| 中文流式聊天 | 通过 | 浏览器发送合成消息并收到本地 9B 的真实回复。SQLite 保存一问一答。 |
| 会话创建、历史、刷新 | 通过 | 浏览器首次发送创建会话，重启及刷新后读取相同历史。 |
| 会话改名和删除 | 通过 | 通过真实网关创建专用合成会话，改名、读取、删除均成功，删除后返回 404。 |
| 停止生成 | 通过 | 浏览器点击停止后显示「已停止」，后端保存未完成状态。DOM 测试覆盖首个 SSE 元数据前取消。 |
| 离线与恢复 | 通过 | 停止隔离服务后浏览器显示离线且禁用输入，重启后同一页面恢复在线。 |
| 记忆、QQ 和微信 | 等待后端 | 浏览器确认记忆页提示等待接入，渠道显示未知。 |
| 真实模型列表与选择 | 部分实现 | 适配器读取已安装模型并选可用的本地 9B/4B。当前无手动切换页面，真实 4B 生成未在本次浏览器联调验证。 |
| 主题、Markdown、移动布局 | 自动化覆盖 | 沿用包内组件。真实手机与局域网未测试，部署限本机。 |

`npm ci --ignore-scripts` 安装锁定依赖 430 个。默认 npm 缓存权限失败后，使用独立缓存重试成功。TypeScript、ESLint、Vite 生产构建通过。Vitest 70 项和网关 Node 7 项通过。网关测试包括跨站拒绝、认证隔离、响应头限制、SSE 透传与后端离线。所有联调对话使用独立测试库。正式本机库专用于日常聊天。
